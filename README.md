# Резюме — Батманов Даниил

Одностраничный сайт-резюме QA-тестировщика. Нежно-зелёная тема, адаптивная вёрстка.

## Содержание

- контакты и желаемая позиция
- навыки (ручное и автотестирование, инструменты, робототехника)
- опыт работы с раскрывающимися блоками
- образование и блок «О себе»

## Структура

```
index.html       — страница резюме
css/style.css    — стили
images/
  mainphoto.jpg  — фото для аватарки
.github/workflows/static.yml — деплой на GitHub Pages
```

## Как открыть

Дважды кликните по `index.html` — сайт откроется в браузере.

## GitHub Pages

После push в ветку `main` сайт публикуется автоматически через Actions.
